# Stroke icons

The original artwork in these six vector icons and its generator is released under CC0-1.0. The `.dat` assets use Blender's VCO geometry format. They are loaded read-only when enabling the extension and released when disabling it.

To edit the silhouettes, change `generate.py` and run it manually with Blender:

```
blender --background --python generate.py
```
